# Neural Network Learning Lab

A hosted interactive study companion for the 23-video neural-network playlist supplied by the user.

## What it does

- Links each video in playlist order
- Gives one ready-made multiple-choice learning question per video
- Offers a hint and an explanation after the user attempts an answer
- Saves completion and quiz statistics locally in the browser
- Includes search and a random recall-review mode

The deployed site is intentionally static. No account, backend, or personal study data is sent to a server.
